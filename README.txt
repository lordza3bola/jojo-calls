JOJO CALLS, MOHAMED RUNS! — installable iPhone app

1. Put this folder online (free)
   Option A, Netlify: go to app.netlify.com/drop, make a free account,
   and drag this whole "jojo-calls" folder onto the page. You get a link
   like something.netlify.app (you can rename it in Site settings).
   Option B, GitHub Pages: upload the folder's contents to a repository
   and turn on Pages in the repository settings.
   Anyone with the link can open it, so only send it to Jojo.

2. Install on the iPhone
   Open the link in Safari > tap Share > "Add to Home Screen" > Add.
   The Jojo icon appears; it opens full screen like a normal app and
   works offline after the first launch.

3. Updating later
   Add or replace files (see assets/manifest.json for how), then open
   sw.js and change VERSION (for example jojo-calls-v2) before uploading
   again. The phone picks up the new version the next time she opens it.
   Her progress is kept.
